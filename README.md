# Professional Portfolio

Personal portfolio site for AIML-500 (Indiana Wesleyan University).

## Structure
- `index.html`: home page (bio, value proposition, artifacts, contact)
- `artifacts/ai-timeline.html`: Artifact 1, AI history timeline
- `assets/`: stylesheet, slide images, PDF and PowerPoint downloads

## Adding a new artifact
1. Copy `artifacts/ai-timeline.html` to a new file, e.g. `artifacts/ai-lab.html`.
2. Replace the visual and the Title, Objective, Process, Tools, and Value sections.
3. Add a new card in the Artifacts grid in `index.html`.
