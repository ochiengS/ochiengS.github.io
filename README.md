# Sharon Ochieng | Professional Portfolio

Portfolio site for AIML-500 (Indiana Wesleyan University), hosted with GitHub Pages at https://ochiengs.github.io

## Files
- `index.html`: home page (bio, value proposition, artifacts, contact)
- `ai-timeline.html`: Artifact 1, AI history timeline
- `style.css`: site styles
- `slide-01.jpg` to `slide-13.jpg`: timeline slide images
- `AI_Timeline_slides_1.pdf`: full timeline

## Adding a new artifact
1. Copy `ai-timeline.html` to a new file (e.g., `ai-lab.html`).
2. Replace the visual and the Title, Objective, Process, Tools, and Value sections.
3. Add a new card in the Artifacts grid in `index.html`.
